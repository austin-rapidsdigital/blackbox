## What's new

Fixes from the live re-test of 0.10.4 (Windows Server 2025 collector, Ubuntu 26.04 sender).

### Accuracy

- **U5** Failed SSH logons on OpenSSH 10 are one row per try. The password check and sshd's logon records for a try are joined by process ID, in either order. Three wrong passwords for an existing user are three rows saying "wrong password or key", and none says "the user name does not exist". A name tried by another connection is never borrowed by address alone.
- **O1** sudo-rs commands without a terminal are read from the journal (its lines have no `TTY=` field). `blackbox check` says that a refused sudo-rs command is logged nowhere.
- **U8** When systemd stops auditd (its record says pid 1, root), the row names the person whose `systemctl stop auditd` asked for it.
- **A15, A5** Blackbox records its own changes. `config set`, setup, upgrades and uninstalls write a row of their own: who, which setting, and the value before and after. A copy also goes to the Windows Application log (source Blackbox) or syslog/journal (ident `blackbox`). A `config set` that changed nothing reads "tried to change … (not applied)". On Windows, `check` and Audit health say whether `C:\ProgramData\Blackbox` has an auditing entry.
- **L9** A file in the inbox that can't be moved aside is no longer reported as "set aside". `status`, the status icon and the report say "1 file in the inbox can't be read (access denied): <name>".
- **U13** "Can stop or weaken auditing" judges each command in a line separately, by its program and arguments. `sh -c "rm -rf /tmp/x; ls /var/log/audit"` and a report command that names the audit log are no longer High.
- **U14** `groupadd` and `groupdel` no longer add "added … to a group" or "removed … from a group" rows, and neither does `userdel -r` removing the user's own group.
- **R10** The printed summary no longer has ISSO / Date / ISSM lines.
- **U15** A stop shorter than a minute reads "less than a minute", not "0 minutes".

### Noise that buried real findings

- **A13** Firewall rules Windows registers for its built-in app packages are one Info row per computer and day, with the counts. A fresh Server 2025 had 123 rows of these. A person changing a rule still gets a row of their own.
- **A14** `groupadd` and the other account tools no longer add "deleted or renamed /etc/group+" and owner or permission rows for their temporary files. Blackbox's own state saves under `/var/lib/blackbox` are left out too. Other programs writing there are still High.
- **W1** Events recorded under a new server's pre-setup name (`WIN-…`) are shown on that server, with a "Recorded under its former name" detail, not as an extra system.
- **W2** OpenSSH for Windows' per-connection `VIRTUAL USERS\sshd_<pid>` account no longer gives "First use of administrator rights".
- **W3** PowerShell's CDXML-generated module code (`$__cmdletization_*`, e.g. `Get-NetFirewallRule`) is recognised in every part of a script, so routine firewall cmdlets are no longer "flagged as suspicious".
- **W4** Windows setup's same-name account renames (4781) and new accounts joining their default primary group "None" (4728) are left out.
